# Security policy

Phyll reads pages, source code and reports written by other people, and Phyll Cloud runs a browser on a server. If you find a way to make any part of it leak data, run code it should not, reach a private network or get around a quota, please report it privately.

Use "Report a vulnerability" on the Security tab of this repository instead of opening a public issue. Say what you did, what happened and which version of Phyll you used.

The skill, the CLI, the GitHub Action and the Phyll Cloud server in this repository are all in scope.
