# The Phyll name and logo

The MIT license covers the code and the content in this repository. It does not cover the Phyll name or logo, which identify this project and the hosted service planned under the same name.

You can use the name to refer to the project, for example "a fork of Phyll", "works with Phyll" or "reviewed with Phyll". Please do not use the name or the logo for a product, a fork or a hosted service in a way that suggests it is the official Phyll or is endorsed by its maintainers.

If you are unsure whether a use is fine, open an issue and ask.
